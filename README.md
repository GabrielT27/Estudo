🛒 EasyCart

Sistema de e-commerce desenvolvido com JavaScript puro, focado na experiência de compra do usuário e na gestão dinâmica de carrinho de compras. A aplicação permite visualizar produtos, adicioná-los ao carrinho, controlar quantidades, calcular valores automaticamente e persistir os dados localmente utilizando LocalStorage.

🎯 Objetivo do Projeto

O objetivo deste projeto foi aprofundar conhecimentos em JavaScript puro através da construção de uma aplicação que simula funcionalidades encontradas em plataformas reais de e-commerce.

Além da implementação visual, o foco principal foi desenvolver a lógica de negócio responsável pelo gerenciamento de produtos, atualização de quantidades, persistência de dados e cálculo automático dos valores da compra.

💡 Principais Desafios
Criar uma experiência de compra intuitiva.
Manter sincronização entre interface e dados armazenados.
Atualizar quantidades e valores em tempo real.
Garantir persistência dos dados utilizando LocalStorage.
Organizar a lógica do carrinho de forma escalável.
